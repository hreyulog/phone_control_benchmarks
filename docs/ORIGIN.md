# 任务来源与范围

100 项来自 2026-10-04 为 Sofia 设计的用户场景库：10 类各 10 项，30 简单、40 中等、30 困难，80 tuning + 20 public holdout，首轮 20 项均来自 tuning。

独立仓库版重新按难度分层选取每类两项 public holdout，共 6 简单、8 中等、6 困难；首轮不与它重叠。这样复测也覆盖简单和中等任务，不只测困难尾部。

设计参考 Sofia 的 App 优先路由、手机原生 Agent、系统 Notes、内置浏览器、文件收发、审批、双机协作和定时事务，以及已知的长文输入、登录循环、来源覆盖和语义推断问题。原始设计时观察到的源码提交为 7eec3bd，Skill catalog 2026-10-04.10；这是设计背景，不是任何新运行的版本证明。发布不含原工作区、真实设备记录、诊断日志、签名包或账号数据。

任务并不保证每一台手机都安装了各 App 或具有 Sofia 协作能力。前置条件与条件型任务在清单中显式保留；不可用须报告。支持其他 Agent 时记录实际执行路径，不宣称不同模式的成绩严格可比。

公开 holdout 仅用于工程迭代后复测，评估时需控制上下文访问；本仓库不声称严格隔离、安全认证或新真机基准成绩。
